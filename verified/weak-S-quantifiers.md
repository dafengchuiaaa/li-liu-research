# A1：最弱 S 的量词等价（条件于原论文定理）

**地位：** 量词构造已独立核对；整条数学等价**依赖** Li–Liu Theorem 6.1 的精确双向谱对应，以及适当的 GRH 条件。未在 Lean 形式化。

设偶数 `N≥4`，`𝔖(N)>0`，`a_N=||T_N||/𝔖(N)`，以及

\[
\eta_N(h)=\frac{h(N)^2(\log N)^3}{N\mathfrak S(N)}.
\]

假设原文给出，在 `0<η_N(h)≤1/4` 范围内谱零点自由条件 `S_N(h)` 与下列范数界等价：

\[
a_N\leq\frac{1}{2h(N)\sqrt{1-\eta_N(h)}}.
\]

**正向：** 固定 `h(N)→∞`，且对所有充分大偶数 `N` 满足 S 与 `η≤1/4`。于是 `a_N≤1/(√3 h(N))→0`。

**反向：** 设 `a_N→0`。定义尾部上确界 `u_N=sup_{M≥N,2|M} a_M`（在充分大偶数 `N` 上有限），令

\[
h(N)=\min\left\{\frac{\sqrt{N\mathfrak S(N)}}{2(\log N)^{3/2}},\ \frac{1}{4\max(u_N,1/\log N)}\right\}.
\]

奇异级数有统一正下界 `𝔖(N)≥2C₂`。因此两项都趋于无穷，故 `h(N)→∞`；第一项给 `η≤1/4`，第二项给 `a_Nh(N)≤1/4`，由此满足原论文范数界并推出 S。若早期有限个 `N` 上构造不适用，可任意定义正 `h`，不影响渐近命题。

**能行性：** `u_N` 的定义可能非可计算，故不自动给出有效收敛率。`h` 与 `T_N` 独立的先验定义问题由“全尾部确定后取值”解决，但并不意味知道它的数值。

**不能由此推出：** S 成立，或者 `||T_N||/𝔖(N)→0` 成立。
